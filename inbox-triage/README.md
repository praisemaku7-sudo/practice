# Inbox Triage Desk

A single-page tool for turning a pasted work email export into:

- a prioritised task list (Do now / Today / This week / FYI)
- a time-blocked plan for the working day
- reply drafts for emails that need a response (with tone and your own steer)
- candid coaching points drawn from the inbox itself

It runs as a claude.ai Artifact and uses the Artifact `sample` capability to call Claude
on the viewer's own account. Opened outside claude.ai, the page still renders (with the
built-in example) but triage and drafting are disabled.

Your role notes, working hours, last triage and ticked tasks are kept in your browser only.
